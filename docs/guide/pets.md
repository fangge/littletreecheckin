# 宠物养成

宠物养成是「成就丛林」里的长期陪伴系统。孩子可以用打卡获得的成长积分领养一只小树宠，陪它从种子一路长到成长期。

## 领养宠物

进入底部导航的「宠物」页面，点击「选择一只宠物」，可以从 6 种宠物中选择：

| 宠物 | 特点 |
|------|------|
| 桃小树 | 软萌多汁，带着蜜桃的甜香 |
| 西瓜小树 | 清爽解暑，带着夏日的瓜香 |
| 苹小树 | 脆甜红润，带着苹果园清香 |
| 梨小树 | 水润清甜，带着梨花的淡香 |
| 莓小树 | 酸甜可爱，带着草莓的奶香 |
| 蕉小树 | 软糯香甜，带着热带的阳光 |

每个孩子同时只能养 1 只宠物。领养后宠物会从「种子」阶段开始。

## 喂养与成长

宠物有 5 个成长阶段：

1. 种子
2. 幼苗
3. 花苞
4. 小树
5. 成长期

每个阶段默认需要 100 / 200 / 300 / 400 / 500 成长积分。成长积分就是孩子现有的果实余额，和商店共用。

- 在宠物页选择 10 / 50 / 100 或输入自定义积分，点击「投入」即可喂养
- 当前阶段喂满后，宠物会进化到下一阶段
- 成长期喂满 500 积分后，宠物毕业，自动收藏为一张宠物卡片
- 如果一次投入超过当前阶段所需，只会扣除实际需要的积分

## 宠物卡片

宠物毕业后会成为一张独立卡片，卡片上记录：

- 宠物种类与毕业阶段
- 累计投入的成长积分
- 成长天数与毕业日期
- 这是第几只同种宠物

同一种宠物可以反复领养，每一只都会单独收藏。

## 家长调整成长规则

家长进入宠物页，点击右上角齿轮，可以调整 5 个阶段分别需要的积分：

- 种子 → 幼苗
- 幼苗 → 花苞
- 花苞 → 小树
- 小树 → 成长期
- 成长期 → 毕业

保存后，正在养的宠物会按新规则和累计投入重新计算阶段。调低门槛可能让宠物提前毕业，调高门槛可能让宠物回到较早的阶段。

儿童模式下不显示家长设置入口，后端也会拦截规则修改请求。
